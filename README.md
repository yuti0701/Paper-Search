# 🧬 Primer: Bio-Diagnostics Research Hub

**Primer**는 분자진단 분야의 연구자를 위한 최신 PubMed 논문 자동 탐색 및 리포트 생성 도구입니다.

## ✨ 주요 기능
- **실시간 PubMed 검색**: 키워드 및 도메인 기반 최신 논문 수집.
- **PowerChek 우선순위**: 특정 키워드(예: PowerChek)가 포함된 논문 자동 하이라이트 및 상단 배치.
- **2열 카드 UI**: 한눈에 많은 정보를 파악할 수 있는 사용자 친화적 디자인.
- **PDF Export**: 원하는 논문을 선택하여 깔끔한 PDF 리포트로 내보내기.
- **Serverless**: 백엔드 서버 없이 브라우저에서 즉시 작동.

## 🚀 배포 방법 (GitHub Pages)
1. 이 저장소를 본인의 GitHub 계정으로 `Fork` 하거나 생성합니다.
2. `Settings` > `Pages` 메뉴로 이동합니다.
3. `Branch`를 `main`으로 설정하고 저장합니다.
4. 잠시 후 제공되는 URL을 통해 웹에서 즉시 접속할 수 있습니다.

## 🛠 기술 스택
