# 🧪 Primer: Bio-Research Intelligence Hub

본 프로젝트는 분자진단 분야의 연구자를 위한 최신 PubMed 논문 자동 탐색 및 리포트 관리 도구입니다.

## 🚀 주요 기능
- **실시간 PubMed 검색**: 최근 발행된 논문을 도메인 및 관심 키워드로 검색합니다.
- **PowerChek 우선순위**: 특정 키워드(예: PowerChek)가 포함된 논문을 최상단에 배치하고 강조합니다.
- **스마트 리포트 발송**: 필요한 논문만 선택하여 교수님께 보낼 리포트 텍스트를 생성하거나 이메일 앱을 연결합니다.
- **반응형 대시보드**: Python 버전의 전문적인 UI를 그대로 웹 브라우저에서 사용할 수 있습니다.

## 🛠 사용 방법
1. `index.html` 파일을 브라우저로 실행하거나 GitHub Pages 주소로 접속합니다.
2. 검색 설정에서 PubMed 이메일 및 날짜를 설정합니다.
3. 리포트 생성 후, 필요한 논문을 체크박스로 선택합니다.
4. 사이드바의 발송 기능을 통해 리포트를 전달합니다.
